# Image Classification System

## Project Overview

A deep learning project for classifying images into predefined categories.
The project explores convolutional neural networks, transfer learning,
model evaluation, and GPU-accelerated training.

## Technologies

- Python
- PyTorch
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Streamlit
- Git and GitHub

## Dataset

The initial dataset will be CIFAR-100, containing 60,000 color images
across 100 classes.

Additional datasets, such as Food-101 and Stanford Dogs, will be
introduced in later stages.

## Planned Features

- Dataset exploration and preprocessing
- CNN model development
- GPU-accelerated training using PyTorch
- TensorFlow/Keras model implementations
- Transfer learning
- Model evaluation and comparison
- Image upload and prediction
- Prediction confidence visualization
- Interactive Streamlit dashboard
- Automated testing

## Project Structure

- `configs/`: Dataset and training configurations
- `data/`: Dataset instructions and local data
- `models/`: Saved model artifacts
- `notebooks/`: Experiments and data exploration
- `src/`: Application and machine learning code
- `tests/`: Automated tests
- `reports/`: Experiment results
- `screenshots/`: Application screenshots
